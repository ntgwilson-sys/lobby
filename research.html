lobby started as a riff on crazy eights. the shedding race stays, but matching suits becomes climbing floors, and the wild 8 becomes the 2 and the ace.

the first draft of lobby looked fine on paper. the trouble only showed up when you played it a few thousand times.

how it was tested: simple computer players dealt real shuffled decks and played by the rules, about 3,000 to 4,000 games for every setup and player count. each player plays the highest card they legally can. it's a rough test, not real people, so treat the numbers as direction rather than gospel. the full script is in exhibit g.

exhibit athe original rules

the game is a race to empty your hand, but almost nobody won that way. the draw deck ran out first in around 9 in 10 games, and players spent a huge chunk of their turns stuck picking up. the suspect: only being allowed to play the same floor or one higher.

exhibit ethe lucky ace

the one lasting imbalance. being dealt at least one ace is a real edge once there are 3 or 4 players. none of the fixes tried closed the gap by more than a point or two: counting the ace as 15 at the end, only allowing it when you can't play anything else, or taking away its extra card. it's built into having a card that goes anywhere, like a wild in uno, so it stays as the lucky card of the deck.

the one choice that really matters: firing your aces off early. a 4 player who does that wins 21% of the time against a fair 25%. saving aces and 2s for later made almost no difference.

exhibit ghow it was tested

every number on this page came from a python script. it builds a real 52 card deck (ace 1 up to king 13), shuffles it, deals the hands, and has simple computer players follow the rules. each one plays the highest floor it legally can and only falls back on an ace or a 2 when it has to.

every setup was played 3,000 to 4,000 times, once for each player count. each game uses a numbered shuffle, so running it again gives the same results. the script counts how games end, how long they take, which seat wins and what each player was dealt. it runs in about a second with python3 sim.py.

# lobby simulator
# plays thousands of games of lobby with simple computer players
# and reports how often someone wins by going out, how long games last,
# and whether any seat or deal has an edge.
#
# run it with:  python3 sim.py

import random
import statistics

ACE, KING = 1, 13


def play_game(players, seed, hand_size=10, max_step=2, sets=True):
    """plays one game with the final rules and returns what happened."""
    rng = random.Random(seed)

    # a standard deck: ace is 1, j 11, q 12, k 13, four of each
    deck = [floor for floor in range(1, 14) for _ in range(4)]
    rng.shuffle(deck)

    hands = [deck[i * hand_size:(i + 1) * hand_size] for i in range(players)]
    draw_pile = deck[players * hand_size:]
    aces_dealt = [hand.count(ACE) for hand in hands]

    def can_play(card, top):
        # the 2 and the ace go on anything,
        # everything else is the same floor or up to max_step higher
        if card in (2, ACE):
            return True
        return 0 <= card - top <= max_step

    def lay(hand, card):
        # play one copy, or every copy if sets are allowed
        copies = hand.count(card) if sets else 1
        for _ in range(copies):
            hand.remove(card)

    def restart(hand):
        # after a clear, start the new pile with your highest card
        # (keeping aces back, since they go anywhere later)
        choices = [c for c in hand if c != ACE] or hand
        card = max(choices)
        lay(hand, card)
        return card

    # whoever holds the lowest card goes first and plays it
    current = min(range(players), key=lambda i: min(hands[i]))
    starter = current
    first = min(hands[current])
    lay(hands[current], first)
    top = restart(hands[current]) if first in (ACE, KING) else first
    current = (current + 1) % players

    turns = 0
    while turns < 3000:
        turns += 1
        hand = hands[current]
        options = {c for c in hand if can_play(c, top)}

        if not options:
            if not draw_pile:
                # deck's empty: lowest total wins, fewest cards breaks a tie
                totals = [sum(h) for h in hands]
                best = min(totals)
                tied = [i for i in range(players) if totals[i] == best]
                winner = min(tied, key=lambda i: len(hands[i]))
                return dict(how="deck ran out", winner=winner, starter=starter,
                            turns=turns, aces=aces_dealt)
            hand.append(draw_pile.pop())  # stuck: pick up and skip
            current = (current + 1) % players
            continue

        # strategy: play the highest normal floor you can,
        # and only fall back on an ace or a 2 when you have to
        normal = [c for c in options if c not in (2, ACE)]
        card = max(normal) if normal else (ACE if ACE in options else 2)
        lay(hand, card)

        if card in (ACE, KING):
            # clear the shaft, then start a new one
            while hand:
                top = restart(hand)
                if top not in (ACE, KING):
                    break
        else:
            top = card

        if not hand:
            return dict(how="went out", winner=current, starter=starter,
                        turns=turns, aces=aces_dealt)
        current = (current + 1) % players

    return dict(how="never ended", winner=None, starter=starter,
                turns=turns, aces=aces_dealt)


def report(players, games=4000, **rules):
    results = [play_game(players, seed, **rules) for seed in range(games)]
    went_out = sum(r["how"] == "went out" for r in results) / games
    turns = sorted(r["turns"] for r in results)
    starter_wins = sum(r["winner"] == r["starter"] for r in results) / games

    with_ace = [0, 0]
    without_ace = [0, 0]
    for r in results:
        for seat, aces in enumerate(r["aces"]):
            bucket = with_ace if aces else without_ace
            bucket[0] += 1
            bucket[1] += r["winner"] == seat

    print(f"{players} players, {rules or 'final rules'}")
    print(f"  won by going out   {went_out:.0%}")
    print(f"  typical game       {statistics.median(turns):.0f} turns")
    print(f"  longest 1 in 10    over {turns[9 * games // 10]} turns")
    print(f"  starter wins       {starter_wins:.0%} (fair share {1 / players:.0%})")
    print(f"  win rate, no ace   {without_ace[1] / without_ace[0]:.0%}")
    print(f"  win rate, 1+ aces  {with_ace[1] / with_ace[0]:.0%}")
    print()


if __name__ == "__main__":
    report(2, hand_size=8)
    report(3)
    report(4)
    # try the original rules for comparison: one floor up, no sets
    report(4, max_step=1, sets=False)

the verdict

what changed

  • go up to 2 floors, not 1
  • play every copy of a floor as a set
  • the ace is 1 and goes anywhere
  • the ace and king both clear
  • 8 cards each with 2 players
  • card values settled for the end

what stayed

  • lowest card starts
  • stuck means pick up and skip
  • the 2 still drops the lift to the lobby
  • no reshuffling the shaft

still open

  • the ace is a lucky card to be dealt
  • not many big decisions per turn
  • long 2 player games happen now and then
  • needs testing with real people

case closed, for now
